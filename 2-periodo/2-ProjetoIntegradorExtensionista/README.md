# Projeto Integrador Extensionista – Desenvolvimento de Software Educativo para Ensino de Estatística

## 📌 Visão Geral

Este projeto foi desenvolvido como parte do **Projeto Integrador Extensionista** do **2º período** no Centro Universitário do Sul de Minas – **UNIS-MG**. Seu objetivo foi criar um **software educativo web** para tornar o ensino de estatística mais dinâmico, acessível e engajador para estudantes do ensino médio.

A plataforma, apelidada de **Statify**, reúne conteúdos teóricos, exercícios práticos e um mapa interativo de módulos, combinando pedagogia, design e engenharia de software em um único produto acadêmico.

O projeto envolveu as etapas completas de engenharia de software — desde análise e prototipação até desenvolvimento, validação com usuários reais e apresentação institucional.

## 📚 Contexto do Projeto

O objetivo era criar uma plataforma que transformasse o ensino tradicional de estatística em uma experiência prática e intuitiva. A solução deveria ser:

* acessível para alunos do ensino médio,
* alinhada ao ENEM e vestibulares,
* simples de usar,
* motivadora, com navegação visual e atividades interativas.

O projeto evoluiu em ciclos: planejamento → prototipação → desenvolvimento → testes → apresentação final.

## 🏆 Conquistas

* Software educativo **totalmente funcional** entregue dentro do prazo.
* Validação acadêmica positiva durante apresentação institucional.
* Implementação de módulos essenciais de estatística.
* Protótipo navegável testado com usuários reais.

> **Métricas quantitativas do projeto (organizadas por categoria):**

* **Telas iniciais do sistema:** 3 telas (login, cadastro e acesso inicial)
* **Telas principais da aplicação (pós-login):** 4 telas (início/apresentação, sobre, mapa de módulos e perfil)
* **Telas de seleção de módulos:** 4 telas (uma para cada módulo distribuído entre os 4 temas)
* **Telas internas dos módulos:** 42 telas ao total, organizadas da seguinte forma:

  * 7 telas de apresentação de módulo (1 por módulo)
  * 7 telas de conteúdo (1 por módulo)
  * 21 telas de exercícios práticos (3 por módulo)
  * 7 telas de exercícios propostos (1 por módulo)

## ▶️ Como executar o projeto

Este projeto pode ser executado de duas formas: **(1) apenas o front-end** ou **(2) front-end + back-end em PHP**. Escolha o modo conforme sua necessidade.


### **1. Executar apenas o Front-end (HTML, CSS e JavaScript)**

Ideal para visualizar o layout, navegação e fluxo geral do Statify.

📁 **Pasta correta para download do projeto**
Baixe o `.zip` da seguinte pasta:
👉 [Acessar pasta de desenvolvimento](https://github.com/LucasCiacci/Faculdade/tree/main/2-periodo/2-ProjetoIntegradorExtensionista/Projeto-Software-Estatistica/Programando/Desenvolvendo%20o%20Projeto)

**Caminho interno da pasta:**
`Projeto-Software-Estatistica/Programando/Desenvolvendo o Projeto/`

**Passo a passo:**

1. Baixe o `.zip` da pasta acima ou copie apenas essa pasta para sua máquina.
2. Extraia o conteúdo (caso tenha baixado o `.zip`).
3. Navegue até a pasta:
   `Primeiras Telas/`
4. Dentro dela, abra o arquivo:
   👉 **`index.html`**
   Esse arquivo é a tela inicial do aplicativo.
5. Navegue normalmente pelo sistema.

> ⚠️ **Limitação:** Telas que dependem de PHP **não funcionarão** nesse modo (ex.: validação de exercícios ou interações com dados). 
---

### **2. Executar Front-end + Back-end (com suporte a PHP)**

Use este modo se quiser testar **validação dos exercícios**, **interações completas**, etc.

**Passo a passo:**

1. Instale o **XAMPP** (ou outro servidor PHP local).
2. Abra o painel do XAMPP e inicie:

   * ✔ **Apache**
3. Localize a pasta `htdocs` dentro da instalação do XAMPP.
4. Cole a pasta completa do projeto dentro de `htdocs`, por exemplo:
   `C:/xampp/htdocs/Projeto-Software-Estatistica/`
5. Acesse o projeto pelo navegador usando:
   👉 `http://localhost/Projeto-Software-Estatistica/index.php`
   (ou o arquivo principal equivalente caso o nome seja diferente)
6. Agora todas as funcionalidades que usam PHP irão funcionar normalmente.
