# 📚 2º Período — Ciência da Computação

Este período aprofunda conceitos de desenvolvimento de software, estruturação de sistemas e análise de dados, com maior integração entre teoria e prática.

## 🎯 Projeto Integrador Extensionista
Projeto interdisciplinar focado no desenvolvimento de um software educativo, aplicando conceitos de engenharia de software, estatística e estruturação lógica.

## 📘 Disciplinas do Período

- **Algoritmos e Estruturas de Dados**  
  Estudo de estruturas fundamentais, organização de dados e eficiência algorítmica.

- **Cálculos e Estatística Básica**  
  Fundamentos matemáticos e estatísticos aplicados à análise de dados e resolução de problemas computacionais.

- **Engenharia de Software**  
  Conceitos de levantamento de requisitos, modelagem, documentação e ciclo de vida de software.

## 🔗 Relação entre Projeto e Disciplinas
O Projeto Integrador utiliza diretamente conceitos de engenharia de software, lógica algorítmica e estatística, permitindo a construção de uma solução estruturada e academicamente validada.
