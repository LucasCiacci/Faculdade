# 🎓 Repositório "Faculdade" – Projetos, Atividades e Estudos Acadêmicos

Bem-vindo ao repositório **Faculdade**, um espaço centralizado criado para organizar e apresentar **todos os projetos, atividades, práticas, exercícios e estudos** desenvolvidos ao longo da minha graduação no **Centro Universitário do Sul de Minas – UNIS-MG**.

Este repositório funciona como um **arquivo acadêmico completo**, mas também como parte do meu **portfólio profissional**, mostrando minha evolução técnica, meus projetos principais e minha experiência prática em diferentes áreas da computação.

---

## 🧭 Sobre este Repositório

Este repositório reúne:

* Todos os **Projetos Integradores Extensionistas** (um por período).
* Atividades, estudos, exercícios e produções das **disciplinas de cada período**.
* Projetos secundários desenvolvidos ao longo das matérias.
* Documentações, slides, relatórios e arquivos de apoio.

Cada período possui uma estrutura própria contendo:

* 📌 Projeto Integrador Extensionista (projeto principal do período)
* 📚 Disciplinas do período com atividades e materiais

O objetivo deste repositório é servir como:

* Uma **linha do tempo organizada** da minha formação.
* Um **portfólio profissional** apresentando meus projetos acadêmicos mais significativos.
* Um lugar único para consultar meu crescimento técnico, minhas entregas e minha produção acadêmica.
