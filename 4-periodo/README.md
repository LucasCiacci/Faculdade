# 📚 4º Período — Ciência da Computação

Este período é direcionado ao desenvolvimento de soluções mobile, análise de dados e gestão de projetos, com foco em aplicações modernas e orientadas a dados.

## 🎯 Projeto Integrador Extensionista
Projeto colaborativo de desenvolvimento de um MVP mobile de Business Intelligence, com dashboards interativos e integração com banco de dados.

## 📘 Disciplinas do Período

- **Banco de Dados Aplicado a Business Intelligence e Big Data**  
  Modelagem, consultas avançadas e uso de dados para análise e tomada de decisão.

- **Gestão de Projetos Ágeis**  
  Princípios ágeis, organização de equipes, planejamento e acompanhamento de projetos.

- **Mobile Technologies**  
  Desenvolvimento de aplicações mobile modernas, com foco em arquitetura, usabilidade e integração de dados.

## 🔗 Relação entre Projeto e Disciplinas
O Projeto Integrador consolida os conhecimentos das disciplinas, unindo mobile, banco de dados e gestão ágil em um MVP funcional de BI.
