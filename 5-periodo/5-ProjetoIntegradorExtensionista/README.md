# Projeto ExpressMe

**Projeto Integrador Extensionista – 5º Período**

## 📖 Sobre o Projeto

O Projeto **ExpressMe** é um sistema tecnológico voltado para suporte e comunicação alternativa, focado em auxiliar crianças com Transtorno do Espectro Autista (TEA). 
Este projeto engloba o planejamento, a ideação e as definições arquiteturais de uma solução desenhada para ser intuitiva e facilitar a interação e expressão diária.

Para maiores detalhes sobre a concepção, veja os documentos:
- Projeto_ExpressMe.pdf (Apresentação Final)
- Desenvolvimento_do_Projeto/Plano_Inicial.pdf (Plano e Estrutura)

## 📂 Estrutura de Arquivos e Pastas

- **1_Etapa**, **2_Etapa**, **3_Etapa**: Documentações, pesquisas e entregas parciais ao longo do semestre.
- **Desenvolvimento_do_Projeto**: Contém arquivos norteadores como o plano inicial e a visão arquitetural do projeto.
- Projeto_ExpressMe.pdf: Arquivo com a consolidação e apresentação final.
