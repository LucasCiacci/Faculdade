# Prompt para IA Manus — Mapeamento Direto e Objetivo

## Contexto

Estou desenvolvendo um projeto acadêmico na faculdade que deverá resultar em um protótipo físico, provavelmente utilizando Arduino.

O objetivo geral é criar uma solução que ajude crianças com autismo (TEA) que possuem dificuldades de comunicação (verbal e/ou não verbal).

Neste momento, NÃO quero desenvolver o projeto nem receber plano técnico detalhado.
Preciso apenas de um mapeamento simples e direto de soluções já existentes para me ajudar a definir qual caminho seguir.

---

## O que você deve fazer

1. Liste entre 5 e 10 projetos reais já existentes (aplicativos, dispositivos físicos, sistemas com sensores, ferramentas educacionais ou pesquisas aplicadas) que tenham como foco principal ajudar crianças com autismo na comunicação.

2. Para cada projeto, apresente de forma objetiva:
   - Nome do projeto
   - Tipo (app, dispositivo físico, sistema com sensores, robô, método pedagógico etc.)
   - Qual problema específico de comunicação ele trabalha
   - Como ele funciona de forma resumida (máximo 5 linhas)
   - Se utiliza hardware físico (sensores, botões, telas, robótica etc.)

3. Após listar os projetos, faça uma síntese curta contendo:
   - Quais tipos de solução aparecem com mais frequência
   - Quais parecem mais viáveis para serem adaptadas para um projeto com Arduino
   - Quais abordagens parecem simples e possíveis de desenvolver em contexto universitário

---

## Restrições

- Não criar um novo projeto.
- Não desenvolver plano de implementação.
- Não escrever textos longos ou teóricos.
- Ser direto, organizado e objetivo.
- Priorizar clareza e aplicabilidade prática.

---

## Objetivo Final

Ajudar a identificar caminhos viáveis para um projeto acadêmico com protótipo físico voltado à comunicação de crianças com TEA.
